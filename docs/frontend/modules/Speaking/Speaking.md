# Speaking Frontend Module

Visible name: `Nói - đối thoại`.

## Screens
- mode/topic selection;
- active conversation;
- session summary/history.

## Active conversation
- chủ đề/HSK;
- transcript/message flow;
- microphone/recording state;
- AI response audio/text;
- end session.
