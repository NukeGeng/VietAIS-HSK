# Vocabulary Frontend Module

## Mục đích

Nền tảng → Từ vựng dùng để học/tra cứu, không phải practice screen.

## Screens

- list/search/filter;
- detail.

## Item
- chữ/từ;
- Pinyin;
- nghĩa;
- audio;
- HSK/status metadata cần thiết.

## Detail
- từ;
- Pinyin;
- nghĩa;
- loại từ;
- audio;
- ví dụ;
- chữ cấu tạo/từ liên quan khi có.
