# Skills Frontend Module

## Mục đích

Trang điều hướng kỹ năng, không sở hữu logic nghiệp vụ chi tiết của Speaking/Translation.

## Kỹ năng hiển thị

- Nghe;
- Đọc;
- Viết;
- Nói - đối thoại;
- Dịch Việt - Trung.

Không dùng labels `Listening/Reading/Writing/Speaking` trong UI chính.

## Routes

```text
/app/skills
/app/skills/listening
/app/skills/reading
/app/skills/writing
/app/skills/speaking
/app/skills/translation
```

Nghe/Đọc/Viết có thể dùng Practice flow phía dưới.

Nói và Dịch route vào module riêng.
