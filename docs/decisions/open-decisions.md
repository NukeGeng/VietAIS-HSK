# Open Decisions

Không tự khóa các quyết định này khi chưa PoC/duyệt:

- authentication provider cụ thể;
- review scheduling algorithm cụ thể;
- Hanzi stroke dataset/version cuối cùng;
- Hanzi validation tolerance/algorithm cuối cùng;
- Speech provider cuối cùng;
- object storage provider;
- CDN provider;
- production hosting topology;
- exact AI model/version khi production.

Khi chốt, tạo/update decision record thay vì sửa ngầm trong code.
