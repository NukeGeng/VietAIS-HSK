# CQRS & Event Sourcing

Command dùng để thay đổi trạng thái.

Query đọc Read Model hoặc Marten documents.

Event Sourcing chỉ dùng khi lịch sử nghiệp vụ có giá trị rõ ràng.

Ưu tiên Event Sourcing:
- ExamAttempt
- Learning milestones quan trọng

Không Event Source:
- Vocabulary
- Hanzi
- Grammar
- Static lessons
- Admin content đơn giản
