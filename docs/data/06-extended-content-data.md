# Extended Content Data

## Story

Tối thiểu:
- title;
- HSK level/difficulty metadata;
- Chinese content;
- Vietnamese translation;
- optional Pinyin;
- optional audio;
- publish status.

## Video

Tối thiểu:
- title;
- source/media reference;
- transcript;
- optional Pinyin/translation;
- HSK/difficulty metadata;
- publish status.

## Resource

- title;
- type;
- description;
- file/link metadata;
- level/topic tags;
- publish status.

## Tool

Chỉ metadata/route/config cho công cụ đã được duyệt.

Không xây generic plugin platform trong scope hiện tại.
